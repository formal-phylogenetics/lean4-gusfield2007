# General mathematics

Lemmas that say nothing about phylogenetics, filed by field as Mathlib files them
(`Combinatorics/`, `Order/`, … in `Gusfield2007/Basic/`) and named as Mathlib would name them, so
that they can be contributed to Mathlib. They import only Mathlib.

There are none here yet. The general lemmas of the formalization, on trees and the sides of their
edges, cuts, contractions, connected components and walks, are in the paper's library, in the
namespace `Gusfield2007`, beside the results that use them (`TreeFacts`, `TreeCuts`,
`TreeContract`, `Components`, `HusonKloepper`).

Before adding one, search Mathlib and lean4-phylogenetics (`Phylogenetics/ForMathlib/`): a lemma
that a second repository of the collection needs moves up the tree, to the lowest node above both
(lean4-phylogenetics, docs/CONVENTIONS.md, Section 4).
